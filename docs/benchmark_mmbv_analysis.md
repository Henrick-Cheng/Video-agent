# MMBench-Video 150 题交叉分析 —— agent 舒适区刻画

> 数据：`benchmarks/mmbv_150.json`（150 题 / 136 视频，分层抽样 seed=42）×
> {vlm_direct@8帧, rag_only, agent_tiered, agent} × runs=1。
> 评分：官方 VLMEvalKit 协议复刻（0-3 语义相似度），judge=qwen-max（测试口径；
> 论文口径将经 JUDGE_* 切 gpt-4-turbo 重评缓存答案）。judge 失败 0/600。
> Token 全部为真实 API usage。本次总消耗 ~8.6M tokens。
> 原始逐题记录：`docs/benchmark_mmbv.json`；标准报表：`docs/benchmark_mmbv.md`。

## 总览

| 方法 | 总分(0-3) | 边际 Tok/Q | 预建/视频 | Break-even |
|---|---|---|---|---|
| vlm_direct@8 | **1.447** | 6752 | — | — |
| agent | 1.193 | 9725 | 13138 | 永不 |
| agent_tiered | 1.053 | **4721** | 12819 | **6.3 题/视频** |
| rag_only | 0.787 | **985** | 13079 | **2.3 题/视频** |

## 发现 ①：幻觉抵抗是结构化记忆的机制性胜利（最大的赢）

| HL 维度（n=15） | vlm_direct | rag_only | agent_tiered | agent |
|---|---|---|---|---|
| 得分 | 0.533 | 2.400 | **2.733** | 2.200 |

官方幻觉维度上图方法 **4-5 倍碾压**：诱导性问题（问视频里不存在的东西）面前，
vlm_direct 顺着编，图方法答"证据中没有"。这不是调参结果，是"答案必须接地到
检索证据"的架构属性。agent_tiered 最高——图注入 + 自主决定是否升级的组合
最不容易被诱导。**这是论文叙事里 agent 架构最硬的一条优势。**

## 发现 ②："长视频 = agent 舒适区"的假设被部分证伪，需修正为更精确的版本

按时长桶切（得分 / 边际 token）：

| 桶 | vlm_direct@8 | agent_tiered | agent |
|---|---|---|---|
| <90s (n=52) | 1.52 / 6894 | 1.06 / 3572 | 1.19 / 8891 |
| 90-180s (n=50) | 1.36 / 6688 | 1.16 / 4715 | 0.92 / 9281 |
| >180s (n=48) | 1.46 / 6664 | 0.94 / 5971 | **1.48** / 11091 |

两个出乎预料：

1. **vlm_direct@8帧 在 ≤6min 上没有塌**（1.52/1.36/1.46 平直）。"固定帧数在长视频
   上覆盖率塌缩"在 6 分钟尺度内不成立——MMBench-Video 的题目多数可从全局可见
   内容回答，YouTube 视频镜头冗余度高。该假设要在 10min+ 才可能显形（未测）。
2. **agent 得分随预建投入增长**（1.19→0.92→1.48；>180s 桶预建 24 帧，图更富），
   在最长桶追平 vlm（1.48 vs 1.46）；vlm 是平的。**外推**（非证明）：更长视频上
   斜率交叉可能发生。这是下一轮 10min+ 实验的动机。

## 发现 ③：多轮假设的最终答案——条件成立

长视频上图方法边际成本 < vlm_direct（图像 token 贵过文本查询），所以预建可以摊回：

- rag_only 边际 985：**同视频问到第 3 题起总成本反超 vlm_direct**（break-even 2.3）
- agent_tiered 边际 4721：第 7 题起反超（break-even 6.3）
- 完整 agent 边际 9725 > 6752：永不回本

对照 AGQA（短视频）：rag_only 边际 953 > vlm 626，**短视频上摊销机制完全失效**。
结论："轮次越多越省"成立当且仅当 **长视频 + 多题/会话 + 低边际应答策略（tiered/rag）**。
MMBench-Video 本身每视频仅 ~1.1 题，所以在该基准的官方口径下这个优势不显形——
它属于多轮会话产品场景，论文中作为成本模型分析呈现，不作为基准胜利宣称。

## 发现 ④：tiered 的自适应真实但有"过度自信"短板

- 150 题中 **90 题（60%）零工具直答**（边际 ~2-3k），升级率随维度感知密度变化
  （FP-C/LR 0.80 次均 > CP 0.27）——运行时决策的又一证据（对照 AGQA：完整 agent
  的工具调用 open 1.81 < binary 2.42 < sequencing 3.21 < duration 3.64）。
- 但 TR 维度 tiered 0.300 vs 完整 agent 0.833：30 题里 22 题直答没升级，图里的
  时序三元组"看起来够用"实则缺因果细节。**缺证升级的判断在"图有相关但不充分
  证据"时失灵**（比缺证更隐蔽）。改进方向：升级判据从"图里有没有"细化为
  "图能不能支撑该题型所需的推理"。

## 发现 ⑤：硬边界——旁白依赖型内容（无 ASR）

TR 全线（vlm 1.333 > agent 0.833 > tiered 0.300）的失分共因：MMBench-Video 大量
"according to the video / mentioned in the video"类问题答案在**旁白音轨**里。
纯视觉管线（我们和 vlm_direct 都是）够不着；vlm_direct 略好是因为 8 帧里常含
字幕/标题帧。**这是当前架构的硬边界，下一轮最高杠杆的改进是加 ASR/字幕通道
入图（三元组来源多一个 modality，架构本身无需改）。**

## 舒适区结论（论文/面试口径）

agent 架构的优势**不是笼统的"长视频"**，而是四个具体条件：

1. **幻觉抵抗 / 可信问答**（HL 4-5×，机制性，任何时长都成立）
2. **结构化时序推理**（AGQA duration 3.7×；MMBench-Video 的 TR 因旁白依赖不可比）
3. **多轮会话经济学**（长视频 + ≥3-7 题/会话时成本反超，见发现 ③）
4. **得分随预建投入可增长**（vlm 固定帧数是平的；10min+ 待验证）

边界（如实披露）：单发问答总分输 vlm_direct（1.193 vs 1.447）；旁白依赖内容
是硬伤；短视频上成本无优势且摊销失效。

## 协议披露

- 抽样：9 个二级维度配额（TR/HL 加密）× 3 时长桶轮转，seed=42，
  脚本 `src/eval/build_mmbench_video.py`
- 多标签题按首叶子维度归主类抽样；聚合按官方多标签逻辑
- vlm_direct 用 8 帧（官方 nframe=8 对齐）；图方法预建帧数 = 时长/15s，夹 [8,24]
- judge=qwen-max 为测试口径（存在 Qwen 评 Qwen 自偏好风险，已知；论文数字
  将用 gpt-4-turbo 对缓存答案重评，零推理成本）
- runs=1：量级和方向供分析；论文数字需 runs=3 ±std
